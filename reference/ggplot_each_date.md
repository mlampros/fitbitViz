# plot function for a single day (heart rate)

plot function for a single day (heart rate)

## Usage

``` r
ggplot_each_date(date_intraday, date)
```

## Arguments

- date_intraday:

  a data.table of Intraday Dates of heart rate measurements

- date:

  a character string specifying a Date

## Value

a plot object of class ggplot2
