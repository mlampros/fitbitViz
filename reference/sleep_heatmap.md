# sleep data heatmap

sleep data heatmap

## Usage

``` r
sleep_heatmap(level_data, angle_x_axis = 0)
```

## Arguments

- level_data:

  a data.table specifying the input level data

- angle_x_axis:

  a float number specifying the angle of the x-axis text of the output
  ggplot

## Value

a plot object of class ggplot2
