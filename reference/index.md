# Package index

## All functions

- [`GPS_TCX_data()`](https://mlampros.github.io/fitbitViz/reference/GPS_TCX_data.md)
  : The GPS-TCX data as a formated data.table
- [`crop_DEM()`](https://mlampros.github.io/fitbitViz/reference/crop_DEM.md)
  : Function to crop the AOI from the downloaded DEM .tif file
- [`extend_AOI_buffer()`](https://mlampros.github.io/fitbitViz/reference/extend_AOI_buffer.md)
  : Extract the sf-object and raster extent based on a buffer (in
  meters)
- [`fitbit_data_type_by_date()`](https://mlampros.github.io/fitbitViz/reference/fitbit_data_type_by_date.md)
  : Process pre-downloaded Fitbit data for Blood Oxygen Saturation,
  Heart Rate Variability, Breathing Rate, Temperature and Cardio Fitness
  Score (or VO2 Max) by Date
- [`gps_lat_lon_to_LINESTRING()`](https://mlampros.github.io/fitbitViz/reference/gps_lat_lon_to_LINESTRING.md)
  : Convert the GPS, TCX data to a LINESTRING
- [`heart_rate_heatmap()`](https://mlampros.github.io/fitbitViz/reference/heart_rate_heatmap.md)
  : Heart Rate Intraday Heatmap (by extracting the 'min.', 'median' and
  'max.' values of the day)
- [`heart_rate_time_series()`](https://mlampros.github.io/fitbitViz/reference/heart_rate_time_series.md)
  : heart rate activity time series
- [`heart_rate_variability_sleep_time()`](https://mlampros.github.io/fitbitViz/reference/heart_rate_variability_sleep_time.md)
  : Heart Rate Variability during Sleep Time (the root mean square of
  successive differences)
- [`leafGL_point_coords()`](https://mlampros.github.io/fitbitViz/reference/leafGL_point_coords.md)
  : Create a Leafet map (including information pop-ups)
- [`rayshader_3d_DEM()`](https://mlampros.github.io/fitbitViz/reference/rayshader_3d_DEM.md)
  : Rayshader 3-dimensional using the Copernicus DEM elevation data
- [`sleep_single_day()`](https://mlampros.github.io/fitbitViz/reference/sleep_single_day.md)
  : Sleep Data of single day
- [`sleep_time_series()`](https://mlampros.github.io/fitbitViz/reference/sleep_time_series.md)
  : Sleep Data Time Series
